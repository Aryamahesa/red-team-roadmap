markdown# Exploit Roadmap - Web Security Learning Tracker

![Status](https://img.shields.io/badge/Status-OWASP%20TOP%2010%20Aligned-green)
---

## 📋 Description

**Exploit Roadmap** is an interactive web application designed to help you track your web security learning progress. This application provides a structured learning path from beginner to expert level, focusing on the most common and dangerous web vulnerabilities based on **OWASP Top 10 (2021)**.

---

## 🎯 Goals

This application helps you to:

- ✅ **Master 80% of vulnerabilities** found in the real world
- 🏆 **Prepare yourself for Bug Bounty Programs**
- 📜 **Get ready for certifications** such as BSCP (Burp Suite Certified Practitioner) and eWPT
- 📈 **Track learning progress** visually and structurally

---

## 📚 Phased Learning (4 Phases)

Content is divided into 4 learning phases based on priority level and complexity:

#### **Phase 1: Foundation (Critical)** - 4 fundamental topics
- SQL Injection
- Cross-site Scripting (XSS)
- Authentication Vulnerabilities
- Access Control Vulnerabilities

#### **Phase 2: Intermediate (High)** - 5 development topics
- CSRF (Cross-Site Request Forgery)
- SSRF (Server-Side Request Forgery)
- XXE Injection
- OS Command Injection
- Path Traversal

#### **Phase 3: Advanced (Medium)** - 8 complex topics
- Server-side Template Injection
- Insecure Deserialization
- Business Logic Vulnerabilities
- File Upload Vulnerabilities
- Information Disclosure
- JWT Attacks
- OAuth Authentication
- NoSQL Injection

#### **Phase 4: Specialized (Specialized)** - 13 specialized topics
- HTTP Request Smuggling
- HTTP Host Header Attacks
- Web Cache Poisoning
- Web Cache Deception
- Clickjacking
- DOM-based Vulnerabilities
- WebSockets
- CORS
- API Testing
- Web LLM Attacks
- GraphQL API Vulnerabilities
- Race Conditions
- Prototype Pollution
